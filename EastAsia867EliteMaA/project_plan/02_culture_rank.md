## 4. 设计约束

1. 三强（中/日/韩）N ≥ 80.5；其余文化一律 < 80.5，档内不得越级；全 mod 上限 **N ≤ 95**、下限 **N ≥ 60**（v5.2）。
2. 原版已有类型避让：han（重步×2/重骑×2/弓兵×1）、japanese（重步/弓骑）、emishi（弓骑）、tangut/shatuo（重骑=MPO 具装弓骑）、viet/tai（象兵科技+传统）——mod 只补空缺类型。
3. 象兵/东南亚科技兵种不设计（云南吃东南亚区域科技，避免重叠）。
4. 东北系（mohe/jurchen/goguryeo/balhae）与西藏系（bodpa 外 5 文化）可共享线内兵种，但**主体文化**（mohe/bodpa）单独成兵种，其余低配共享。
5. 位阶定档后，逐文化设计时按 `01_culture_maa_matrix.md` 兵种方向 + `00_balance_model.md` 模型重算数值，N 不得越档。
