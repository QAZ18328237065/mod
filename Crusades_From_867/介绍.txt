《十字军与吉哈德867解锁》mod 介绍
========================================

【作用】
让 867 年（以及 867~1178.10.1 之间任意开局日期）开局即可发动大圣战，并且是全宗教生效：
  - 原版中"大圣战时代"是随事件解锁的：天主教十字军最早 1095 年（耶路撒冷陷落），
    无条件开放要到 1100.1.1；且原版只为基督教、伊斯兰两个宗教族提供解锁。
  - 本 mod 在开局时直接对【全部宗教族】打上解锁标记（every_religion_global 遍历），
    任何信仰只要自身条件达标，867 年起即可发动大圣战，不再等待 1095/1100。
  - 额外新增：世俗领袖（如哈里发）也能享受【完整版】大圣战
    （原版完整版玩法只对精神领袖开放，见下方说明）。

【使用方式】
无需任何操作，加载即生效。开局后满足原版发动条件即可：
  - 必须由宗教领袖发动（精神领袖如教宗、世俗领袖如哈里发）
  - 宗教狂热 ≥ 75
  - 信仰教义合法（见下方【各宗教玩法指南】）
  - 目标王国内至少 5 个伯爵领可与己方开圣战
  - 同一宗教两次大圣战之间仍有 30 年冷却（原版机制，未改动）
  - 解锁后有约 4 个月缓冲，避免开局多宗教同时刷屏（原版机制，未改动）

【各宗教玩法指南】——对照你的信仰，按对应路径操作：

一、直接就能玩（原版默认配置即可，本 mod 只负责解锁）：
  - 天主教等基督教系：信条"武装朝圣" + 精神领袖（教宗）→ 十字军
  - 逊尼/什叶等伊斯兰系：信条"顺服斗争" + 世俗领袖（哈里发/伊玛目）
    → 吉哈德，且在本 mod 下能玩完整版（准备期/捐金/受益人/封王）
  - 注意：若狂热不足 75 就等它涨上去，或靠胜利/美德提高狂热

二、需要"改革信仰"才能玩（未改革异教）：
  - 北欧、斯拉夫、西非、腾格里等未改革原始宗教
  - 流程：占 3 个圣地 → 改革决议 → 教义里选：
    ① 宗教领袖：世俗或精神领袖（二选一）
     ② 核心信条：战争狂人（great_holy_wars_active_if_reformed，改革后生效）
  - 改革完成后，教主每月自动检查，达标即发动

三、需要"创建新信仰"才能玩（已组织化、但原版没条件）：
  - 适用对象：印度教、佛教、道教、儒家、神道教、琐罗亚斯德教等东方宗教，
    以及所有原版"无宗教领袖"教义（doctrine_no_head）的宗教族
  - 原因：大圣战硬性要求"存在宗教领袖"；这些宗教族大多在族级教义锁死"无领袖"
  - 流程：花大笔虔诚【创建新信仰】（不是改革！）→ 教义里选：
    ① 宗教领袖：改为"精神领袖"或"世俗领袖"
       （神道教等选"世俗领袖"会被自带教义冲突挡住——"世俗教权制"和
        "固定精神任命"，需在同一界面一并改掉；选"精神领袖"无冲突）
     ② 核心信条：选"战争狂人"（东方宗教均可选，不在排除名单）
    ③ 宗教态度：选"原教旨主义"——否则同宗教其他信仰只是"迷途"，
       打不了圣战（日本 867 周边全是神道教，想打本土必须选这个）
    ④ 千万别选"和平主义"或"达摩和平主义"（机制上永久排除大圣战）
  - 新信仰狂热开局 100（≥75 达标），创建时自动设立教主
  - 教主每月自动检查，狂热、目标都满足就自动发动完整版大圣战

四、永远玩不了的：
  - 带"和平主义"（tenet_pacifism）或"达摩和平主义"信条的信仰（机制永久排除）
  - 未改革状态下的原始宗教（未改革本身禁止，需先走第二条改革）

【实现原理】
- 在 on_game_start 上追加一个 on_action（官方规范写法 on_actions = {...} 合并，
  不覆盖、不修改任何原版文件）
- 开局日期 ≥ 867.1.1 且 < 1178.10.1 时，用 every_religion_global 给全部宗教族
  设置原版解锁变量 variable_ghw_unlocked + 120 天缓冲变量
  （缓冲变量与原版 great_holy_war.0010 解锁行为一致）
- 1178.10.1 之后的开局原版已自带解锁（仅基督教/伊斯兰），本 mod 自动跳过
- 世俗领袖完整版原理：
  原版 great_holy_war.0001 事件（精神领袖 AI 发动入口）硬编码了
  doctrine_spiritual_head 教义，事件 ID 无法重定义，故本 mod 复制其发动流程
  为新事件 zzz_crusades_ghw.0001，挂 on_faith_monthly 月脉动，硬性要求
  doctrine_temporal_head —— 精神领袖仍走原版 0001，世俗领袖走本事件，互不重复；
  发动后的准备期/宣誓/捐金/受益人/封王全部由原版引擎驱动，与十字军完全一致

【范围说明】
- 只解锁大圣战（十字军/吉哈德/大净化/大圣战），其余原版时代机制
  （文化时代、MAA 升级、高等级建筑、文化传统等）一律不动
- 附带的原版效果：依赖"大圣战时代已开启"的奥特莱马帝国、
  奥特莱马文化两个决策也会随之提前可用（原版关联，非本 mod 改动）

【兼容性与扩展】
- 全部为新增文件，不修改/覆盖任何原版文件，卸载即完全移除
- 若只想解锁特定宗教而非全部：把 every_religion_global 换成
    religion:xxx = { set_variable = { name = variable_ghw_unlocked value = yes } }
  （仍需该宗教有合法教义与宗教领袖，否则无法发动）
- 只想要 867 书签生效（排除 1066 等后续开局）：
  在 limit 中追加一条 NOT = { game_start_date >= 868.1.1 } 即可
